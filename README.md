# 📊 Sheet Dashboard

เว็บสำหรับสร้าง **Dashboard report** จากข้อมูลใน **Google Sheet** พร้อมระบบ **แนะนำประเภทกราฟที่เหมาะสม** ให้อัตโนมัติ

เป็นเว็บแบบ static ล้วน (HTML + CSS + JavaScript) ใช้ [Chart.js](https://www.chartjs.org/) ในการวาดกราฟ และดึงข้อมูลจาก Google Sheet ผ่าน gviz endpoint โดย **ไม่ต้องใช้ API key**

## ✨ คุณสมบัติ

- **หน้า Dashboard** เป็นหน้าหลักสำหรับแสดงกราฟหลาย ๆ อันพร้อมกัน (เพิ่ม / ลบ การ์ดกราฟได้)
- **เพิ่มข้อมูลจาก Google Sheet** โดยวางลิงก์หรือ ID ของ Sheet
- **เลือก Tab (ชีตย่อย)** ที่จะดึงข้อมูลได้ — ระบุชื่อ tab เอง
- **เลือกประเภทกราฟ** ได้เอง (Bar, Line, Pie, Doughnut, Radar, Polar Area, Scatter)
- **ระบบแนะนำกราฟอัตโนมัติ** — วิเคราะห์โครงสร้างข้อมูล (คอลัมน์วันที่ / ตัวเลข / หมวดหมู่) แล้วเลือกกราฟ + แกน + ค่าที่เหมาะสมให้

## 🚀 วิธีใช้

1. เปิด Google Sheet ของคุณ → **Share** → ตั้งค่าเป็น **"Anyone with the link"** (ทุกคนที่มีลิงก์)
2. คัดลอกลิงก์ Sheet มาวางในช่องด้านซ้าย
3. ใส่ชื่อ Tab ที่ต้องการ (เว้นว่างไว้เพื่อใช้ tab แรก) แล้วกด **ดึงข้อมูล**
4. ระบบจะแนะนำกราฟให้ — กด **ใช้เลย** หรือปรับประเภท/แกน/ค่าเอง แล้วกด **แสดงกราฟบน Dashboard**

## 🔧 การทำงานภายใน

| ไฟล์ | หน้าที่ |
|------|---------|
| `index.html` | โครงหน้าเว็บ |
| `assets/css/style.css` | สไตล์ทั้งหมด |
| `assets/js/sheets.js` | ดึงและแปลงข้อมูลจาก Google Sheet |
| `assets/js/recommend.js` | ตรรกะแนะนำประเภทกราฟ |
| `assets/js/app.js` | เชื่อม UI และวาดกราฟ |

## 📄 หมายเหตุ

- ข้อมูลทั้งหมดถูกดึงและประมวลผลใน **เบราว์เซอร์ของผู้ใช้เท่านั้น** ไม่มีการส่งข้อมูลไปเซิร์ฟเวอร์อื่น
- รองรับเฉพาะ Google Sheet ที่แชร์แบบสาธารณะ (public) เท่านั้น
